What a DNO Application Involves

Every solar system that connects to the grid has to be registered with the local distribution network operator. What that means in practice depends on the system.

G98 or G99

G98
≤ 16A

per phase · notify within 28 days

G99
> 16A

per phase · approval before install

Systems up to 16A per phase — around 3.68kW single phase, 11.04kW three phase — fall under G98. That's a notification: you install, commission, and tell the network operator within 28 days.

Anything above that is G99. That's an application, and you don't install until it's approved. Get the judgement wrong and you either delay a job that didn't need delaying, or commission a system the DNO hasn't agreed to.

Batteries complicate it. A battery counts as generation, so a modest solar array with storage attached often lands in G99 when the panels alone wouldn't.

Where applications fall over

Most rejections have nothing to do with the quality of the install:

  • A superseded inverter type test reference
  • The wrong form for the phase configuration
  • Export limitation asserted without the G100 evidence behind it
  • Existing generation on site not declared
  • A missing single-line diagram on a G99
  • Queries left unanswered until the application drops out of the queue

None are difficult. All are easy to make at seven in the evening with nine other things outstanding.

DNO Application FAQs

The questions installers ask us most.

What is a DNO application?

A DNO application is how a solar system gets registered with the local distribution network operator that owns the cables serving the property. Depending on size it is either a G98 notification, which you send after commissioning, or a G99 application, which has to be approved before you install.

How long does DNO approval take?

G98 has no waiting period at all — you notify within 28 days of commissioning. G99 gives the network operator a statutory window to respond, commonly up to 45 working days for a standard distributed generation application. Fast-tracked smaller Type A systems often come back sooner, and constrained networks or sites needing reinforcement take longer.

Do I need a DNO application for solar panels?

Yes, for any grid-connected system. The route depends on inverter output per phase, not panel capacity. Up to 16A per phase — roughly 3.68kW single phase or 11.04kW three phase — is a G98 notification. Above that is a G99 application. Adding a battery usually pushes a system into G99 because storage counts as generation. Full breakdown here.

When should I submit a DNO application?

For G99, at the point the job is won — not the week before the scaffold arrives. The operator's assessment window runs independently of your schedule, and installing ahead of approval risks having to modify a commissioned system if conditions are imposed. For G98 the constraint is the 28 day window after commissioning. More on timing.

How much does a DNO application cost?

The network operator doesn't charge for G98 notifications or straightforward G99 applications. Costs arise only where network reinforcement, a witness test or other admin charges are required. Our own fee is flat per application, priced separately for G98 and G99 because the work involved is materially different. See pricing.

Who is my DNO?

It's set by geography, not by who supplies the electricity. There are six distribution network operator groups across Great Britain, and the first two digits of the MPAN identify which one covers the site. Find yours.
